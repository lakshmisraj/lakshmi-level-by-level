# Lakshmi, Level by Level

A pixel game of growing up, from Ryan International School at age 3 to Brooklyn in 2026. Eight chapters, mini-games (chess, Bharatanatyam rhythm, a first program, olympiad problems, crashing pods), a memory book, and an original chiptune score in the style of each era's music.

**Play:** https://lakshmisraj.github.io/lakshmi-level-by-level/

Controls: arrow keys or WASD to walk, E or Space to look and talk, M for the memory book. On a phone, use the on-screen pad.

A single static `index.html`, no build step.
